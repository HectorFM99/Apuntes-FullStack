## 🚀 Orden de estudio recomendado

1. `01` → entender la sintaxis y **cómo se enlaza** el CSS al HTML.
2. `02` → aprender a **apuntar** al elemento correcto (el 90% de los problemas de CSS son selectores mal puestos).
3. `03` y `04` → propiedades básicas y modelo de caja.
4. `05` y `06` → **Flexbox y Grid**, la maquetación moderna.
5. `07`, `08`, `09` → interacción, responsive y animaciones.
6. `10` → verlo todo junto en código real.
