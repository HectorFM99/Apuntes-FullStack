## 🚀 Orden de estudio recomendado

1. `01` → la base de todo (sin esto nada más funciona).
2. `02` → control de flujo.
3. `03` → funciones.
4. `04` y `05` → arrays y objetos (el 80% del JS real).
5. `06` → **DOM y eventos** = JS que se ve en la página.
6. `07` → código real completo de tus proyectos.

## 💡 Diferencia clave con HTML/CSS

```html
<!-- HTML: estructura -->
<h1 class="titulo">Hola</h1>
```
```css
/* CSS: diseño */
.titulo { color: red; }
```
```js
// JS: comportamiento
document.querySelector(".titulo").addEventListener("click", () => {
  alert("¡Me has clicado!");
});
```
